# Art Parlour (Landing Page)
A responsive landing page for *Art Parlour*, a fictional vintage art print store.

## Features
- Responsive landing page
- Flexbox-based layout
- Custom typography and color palette
- Featured artwork section
- Call-to-action section
- Clean and minimal design


## Built With
- HTML5
- CSS3
- Flexbox


## What I Learned
Through this project, I practiced:
- Building page layouts with Flexbox
- Creating responsive designs
- Organizing HTML structure
- Applying spacing and visual hierarchy
- Working with reusable CSS styles


## Acknowledgements
This project was built as part of **The Odin Project** Foundations curriculum to practice HTML, CSS, and Flexbox.
The design concept and branding were customized into a fictional vintage art print store called *Art Parlour*.
